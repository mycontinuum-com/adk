# Security Policy

The ADK runs production clinical workflows, and we treat reports accordingly.

## Reporting a vulnerability

Please use **GitHub's private vulnerability reporting** on this repository (Security tab → "Report a vulnerability"). Reports go directly to the maintainers without public disclosure.

Please do not open a public issue for a suspected vulnerability.

## Scope

- The `@animahealth/adk` package as published to npm, and the code in this repository.
- The most recent release. The ADK is pre-1.0; fixes ship as new releases, not backports.

## What to expect

We will acknowledge your report, keep you informed as we investigate, and credit you in the release notes for a confirmed fix unless you prefer otherwise.
